🥶 KEKURANGAN & RUANG IMPROVEMENT (The Bottlenecks)
AI Kurang Proaktif (Cuma Mode "Nengok ke Belakang") Saat ini, AI kita berstatus sebagai Auditor (ngomel/muji setelah bulan selesai di menu History). Si Poros belum berfungsi sebagai Planner di awal bulan.
Solusi/Peluang: Bikin fitur "AI Budget Recommender" saat user buka halaman konfigurasi Budget di tanggal 1. AI yang milihin berapa jatah Nongkrong atau Belanja berdasarkan gaji bulan ini.
Pencatatan Masih "Kuli" (Manual Text Entry) Fitur nambah pengeluarannya cepet, tapi user tetep harus ngetik nominal dan nama barang ("Beli kopi - 30.000") pakai jari kelingking. Kalau lagi capek, user pasti males nyatet.
Solusi/Peluang: Bikin tombol "AI Scan Struk" (pake Vision AI AI Gemini buat baca foto bon) atau "AI Voice Record" (user tinggal ngomong: Ros, gw baru beli seblak 15 ribu pakai porsi double).
Sistem "Target Goal" Keteteran Tanpa Progress Bar Di profil, user cuma nulis target bentuk text ("Beli iPhone"). AI cuma tau nama targetnya, tapi aplikasinya nggak tau udah kekumpul berapa persen uang sisa user untuk beli iPhone itu.
Solusi/Peluang: Bikin tabel Goal Saving terpisah di Dashboard (Goal Name: iPhone 15, Target: 15.000.000, Terkumpul: 5.000.000). Jadi setiap kali AI nyuruh "Simpan sisa gajimu", uangnya beneran masuk ke celengan virtual itu.
Gamifikasi Kurang Berasa Kita udah punya "Health Score" (misal 90/100). Tapi abis itu... ngapain? Nggak ada reward psikologis.
Solusi/Peluang: Terapin sistem Leveling/Badge bulanan. Kalau Health Score di atas 80 selama 3 bulan berturut-turut, user dapat lencana virtual "Sang Penguasa Harta", dsb.
Belum Ada Ekspor PDF/Excel Orang jompo atau user serius kadang butuh datanya dicetak buat bukti laporan. Saat ini data mereka terperangkap di dalam UI kita doang.
